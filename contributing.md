# Contributing

Suggest resources and tracks with a GitHub Issue. Do not open a pull request with new links.

Use [Suggest a resource](.github/ISSUE_TEMPLATE/suggest-resource.yml) or [Suggest a track](.github/ISSUE_TEMPLATE/suggest-track.yml).

A suggestion has to be:

- Free to use with no paywall for the core material.
- On-topic for an existing track, or a new AI/ML track that is not already in `STATUS.md`.
- Something you would actually recommend, with one sentence for why.
- A live URL. Check it before you file.

Duplicates, paid courses, and general software-interview material will be closed.

The maintainer ranks and writes the list entries. If the issue is accepted, the link shows up in the matching track with original wording, not a paste of your issue text.
